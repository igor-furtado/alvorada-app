# Priorizar múltiplos Concursos sem duplicar estudo

Cada Tópico é uma unidade única e compartilhada entre Editais, portanto aparece uma vez no catálogo mesmo quando pertence a mais de um Concurso. Sua prioridade usa o peso combinado — soma da relevância normalizada em cada Edital, ponderada pela proximidade das provas — enquanto o Concurso escolhido como prioritário define o corte quando necessário; a prova mais próxima desempata. Essa escolha evita duplicar conteúdo e mantém a redução de escopo explícita, em vez de deixar o aplicativo decidir silenciosamente qual Concurso abandonar.

## Alternativa considerada

Priorizar sempre a prova mais próxima seria mais simples, mas poderia consumir todo o tempo com um Concurso secundário de baixa relevância pessoal.
