# Triage Labels

As skills usam cinco papéis canônicos de triagem. Esta tabela mapeia cada papel para o label utilizado no GitHub.

| Papel canônico    | Label no GitHub    | Significado                                  |
| ----------------- | ------------------ | -------------------------------------------- |
| `needs-triage`    | `needs-triage`     | Precisa ser avaliada pelo mantenedor         |
| `needs-info`      | `needs-info`       | Aguardando informações adicionais            |
| `ready-for-agent` | `ready-for-agent`  | Especificada e pronta para um agente autônomo |
| `ready-for-human` | `ready-for-human`  | Requer implementação ou decisão humana       |
| `wontfix`         | `wontfix`          | Não será implementada                        |

Quando uma skill mencionar um papel de triagem, use o label correspondente desta tabela. Edite a segunda coluna se o repositório adotar outro vocabulário no futuro.
