# Prumo.app — Flutter Web

Interface do aplicativo de gerenciamento de estudos para concursos públicos. As telas principais usam dados demonstrativos enquanto os fluxos de produto são validados; a integração com a API será feita em uma etapa posterior.

```bash
flutter run -d chrome
```

O design system fica em `lib/src/core/theme/`, a navegação compartilhada em `lib/src/core/presentation/` e os SVGs em `assets/brand/`. A documentação para agentes está separada entre `docs/agents/brand/`, `docs/agents/product/` e `docs/agents/design-system/`.
