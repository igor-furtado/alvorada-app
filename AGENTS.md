## Agent skills

### Issue tracker

Issues e especificações são gerenciados no GitHub. Consulte `docs/agents/issue-tracker.md`.

### Triage labels

São utilizados os cinco labels canônicos de triagem. Consulte `docs/agents/triage-labels.md`.

### Domain docs

O projeto usa documentação de domínio single-context. Consulte `docs/agents/domain.md`.

### Marca

Ao alterar nome, posicionamento, assinatura, identidade, assets, metadados de marca ou materiais de loja, siga `app/docs/agents/brand/index.md`.

### Produto

Ao alterar comportamento, método, priorização, descanso, métricas, navegação, vocabulário ou termos do produto, siga `app/docs/agents/product/index.md`.

### Flutter UI

Ao alterar widget, fluxo, texto, navegação, responsividade ou acessibilidade Flutter, siga `app/docs/agents/design-system/index.md`.
